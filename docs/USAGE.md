# QuoteMint 产品与角色说明（怎么用 / 谁在用 / 怎么管理）

> [English](USAGE.en.md) | 中文

> 面向创始人了解产品全貌，也帮助未来加入的人快速看懂"谁在用什么、怎么用、谁在管"。技术细节见 [ARCHITECTURE](ARCHITECTURE.md)；日常操作见 [OPERATIONS](OPERATIONS.md)；平台全表见 [PLATFORMS](PLATFORMS.md)。

## 1. 产品是什么

- **网址**：https://quotemint.dpdns.org （中英双语，自动按浏览器语言显示，右上角可手动切换）
- **核心循环**：发报价 → 客户打开（你看到打开记录）→ 客户在线签收（输入姓名即电子签收）→ 随时打印/存 PDF
- **为谁做**：自由职业者与 1–3 人小工作室；不面向企业销售团队

## 2. 四种角色一览

| 角色 | 要注册吗 | 干什么 | 花钱吗 |
|---|---|---|---|
| **用户 · 免费版** | 要（邮箱+密码，1 分钟） | 每月 3 份报价、客户在线签收、打印 PDF | ¥0 |
| **用户 · 专业版 Pro** | 同上（升级而来） | 无限报价、去掉"Powered by QuoteMint"标识、自定义品牌（公司名 / Logo 文字 / 主色）、完整打开动态 | ¥68/年（支付宝扫码） |
| **客户**（收报价的人） | **完全不用注册** | 点链接看报价、输姓名签收（或拒绝）、打印保存 | ¥0 |
| **运营者（老板）** | — | 收款开通、回信、巡检 | — |

> 产品内没有面向普通用户的后台；运营者有独立的**隐藏管理端 `/admin`**（默认对外 404、需管理员密码，见 §6）。

## 3. 免费版 vs 专业版

| | Free | Pro（¥68/年，海外路线 $9/月 待启用） |
|---|---|---|
| 报价数量 | 每月 3 份 | 无限 |
| 网站标识 | 报价页带 "Powered by QuoteMint" | 无标识 |
| 品牌自定义 | — | 公司名 / Logo 文字 / 主色 |
| 打开动态 | 基础状态（已发送/已打开/已签收） | 完整时间线（每次打开都有记录，编辑器内可见） |
| 开通方式 | — | 账单页扫码付款 → 发邮件 → 运营方运行开通命令 |

## 4. 用户旅程（自由职业者）

1. **注册**：打开网站 → 邮箱+密码注册（无需邮箱验证）。
2. **新建报价**：标题、客户名、明细项（描述 / 数量 / 单价）、折扣、税、备注与条款、有效期。金额实时计算。
3. **发送**：点"发送"生成**专属链接**（形如 `/q/<随机令牌>`）——没有邮件发送功能，链接由用户自行通过邮件/微信发给客户（v1 设计如此）。
4. **等待打开**：客户一打开链接，用户就能在报价的"动态"面板看到打开记录。
5. **签收**：客户输入姓名、勾选同意、点击签收 → 状态变"已签收"，显示签收人姓名与时间。
6. **归档**：打印或另存为干净的 A4 PDF（自动隐藏按钮和导航）。
7. **升级**：免费版当月第 4 份时报"已达上限" → 账单页扫码付 ¥68/年 → 发邮件到 support@ → 运营方开通 Pro → 立即生效。

## 5. 客户旅程（签收方）

- 点开链接**无需注册登录**，直接看到报价页面（草稿状态会显示 DRAFT 水印）。
- **同意**：输入姓名 + 勾选同意条款 → 点签收 → 页面立即显示"已签收"与时间戳。
- **不同意**：点拒绝，可选填理由。
- 任何状态都可打印/存 PDF；同一访客的重复打开 60 秒内去重，不会刷屏。

## 6. 运营者（老板）视角：怎么管理

| 管理事项 | 在哪里做 | 频率 |
|---|---|---|
| 收到付款通知 / 客户来信 | **QQ邮箱**（support@ 自动转发到此） | 每天看一眼 |
| 以 support@ 名义回信 | exmail.qq.com 微信扫码登录 | 有事时 |
| 给客户开通 Pro | 打开 https://quotemint.dpdns.org/admin（管理员密码在 `账号信息.md`）→ 搜索邮箱 → 点"开通专业版"；或把邮箱发给 Claude | 有付款时 |
| 核对收款 | 支付宝账单 | 有事时 |
| 网站 / 数据库用量 | Netlify、Neon 控制台 | 偶尔 |
| 域名续期 | DigitalPlat（2027-10-13 到期，免费续） | 每年一次 |
| 改网站上任何东西 | 直接告诉 Claude → 推送 → 约 1 分钟自动上线 | 随时 |

日常只有两件事：**看邮件 + 在管理端开通**（管理端打不开时再找 Claude）。详细步骤见 [OPERATIONS](OPERATIONS.md)。

## 7. 数据与安全速览

- 用户与报价数据存放在云端 Neon Postgres；本地开发用 SQLite，互不影响。
- 签收为 **typed-name 电子签名**（v1 不做证书级签名），记录姓名 + 时间戳存证。
- 客户侧无注册、无追踪像素；打开记录仅统计"打开时间与次数"。
- 密码加密存储、会话令牌哈希化；公开仓库不含任何凭证（详见 API-CONTRACT 与 PLAYBOOK 的安全章节）。
