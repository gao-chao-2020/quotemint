# QuoteMint 运营操作说明（给老板的手册）

> [English](OPERATIONS.en.md) | 中文

> 本手册写给非技术背景的创始人。日常需要你亲自做的只有几件事；其余都可以交给 Claude。所有账号密码见本地 `账号信息.md`（副本备份在私有仓库 quotemint-ops），本手册不写密码。

## 0. 一分钟总览

- **网站**：https://quotemint.dpdns.org （自动部署、自动 HTTPS；月固定成本 ¥0）
- **客服邮箱**：support@quotemint.dpdns.org —— 来信**自动转发到你的常用QQ邮箱**，平时看QQ邮箱即可
- **收款**：支付宝收款码（在网站账单页展示）→ 收到款后运行一条开通命令
- **钥匙**：密码都在 `账号信息.md`（电脑本地 + 私有仓库备份），别外传

## 1. 收到支付宝付款（最常见的操作）

1. 你会先在邮箱（或支付宝/微信）看到付款消息，内容会说明付款人的**注册邮箱**。
2. 核对：金额 ¥68、留言里的注册邮箱。
3. **开通**：在电脑上打开终端，执行：

   ```
   cd D:\test\创业公司
   npm run grant <客户的注册邮箱> 12
   ```

   （`12` = 开通 12 个月。这条命令连的是线上正式数据库，本地运行即可。）
4. **回信客户**：打开 https://exmail.qq.com → 用微信扫码登录 → 写信 → 把「发件人」切换成 support@quotemint.dpdns.org → 告诉客户"已开通，刷新账单页即可"。
5. 不想自己弄：把付款截图发给 Claude，说一句"给这个邮箱开通"，就完成了。

## 2. 收到客户咨询邮件

- **简单回复**：直接在QQ邮箱里回复即可（发件人是你的QQ地址，代表个人身份）。
- **要正式一点**（以 support@ 名义回复）：到 https://exmail.qq.com 微信扫码登录后回复，或让 Claude 起草内容。
- 拿不准怎么回：把邮件内容发给 Claude，让它拟一版你再改。

## 3. 想改网站上的东西（文案、价格、功能）

1. 直接告诉 Claude"改什么"。
2. Claude 修改并推送后，约 1 分钟自动上线，不用你做任何操作。
3. 改完建议在浏览器里实际点一遍确认。

## 4. 每月巡检（约 10 分钟）

- [ ] 网站探活：浏览器打开 https://quotemint.dpdns.org/healthz ，显示 `ok` 即正常
- [ ] Netlify 用量：登录 Netlify 控制台 → Usage（免费档每月 300 credits，正常量级用不完）
- [ ] Neon 用量：登录 Neon 控制台看存储/计算（免费额度对早期足够）
- [ ] 看一眼数据：注册数、报价数（可以让 Claude 直接查询给你）

## 5. 每年要做的事

- [ ] **域名续期**：`quotemint.dpdns.org` 有效期到 **2027-10-13**；到期前 120 天即可在 DigitalPlat 面板免费续期（到期前 Claude 也会提醒你）
- [ ] 发一封测试邮件到 support@，确认QQ邮箱能收到（验证自动转发仍有效）

## 6. 出了问题怎么办

| 问题 | 先做什么 | 再不行 |
|---|---|---|
| 网站打不开 | 打开 https://www.netlifystatus.com 看 Netlify 是否故障 | 找 Claude 查部署日志 |
| 邮箱收不到信 | 检查QQ邮箱的垃圾箱 | 找 Claude 检查转发设置 |
| 忘记某平台密码 | 看 `账号信息.md` | GitHub 用绑定邮箱找回；Netlify/Neon 都是"GitHub 一键登录" |
| 收到奇怪的扣费/绑卡要求 | **先停**，什么都别点 | 先问 Claude 确认是否钓鱼 |

## 7. 安全守则（三条）

1. `账号信息.md` 不要转发、不要截图发给别人；它已备份在私有仓库（仅你可见）。
2. 任何平台要求"转账 / 绑银行卡 / 付费订阅"之前，先问 Claude 确认。
3. 以后如果有员工/帮手，把密码迁到密码管理器（如 Bitwarden 免费版）再共享，Claude 可以帮你迁。

## 8. 名词速查

| 名词 | 白话解释 |
|---|---|
| 部署 / 上线 | 把新的代码更新发布到网站上的过程（推送后自动完成，约 1 分钟） |
| Netlify / Neon / DigitalPlat | 分别负责"网站服务器 / 数据库 / 域名"的免费服务商 |
| Pro 开通（grant） | 把某个注册用户升级为付费版（收款后执行一条命令） |
| 别名邮箱 | support@ 和你主邮箱"同一把钥匙开两扇门"：别人发到 support@，邮件进你的邮箱 |
| 自动转发 | 邮箱收到信后自动抄送一份到你常用的QQ邮箱 |
