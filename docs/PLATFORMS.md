## 平台之间的关系

```
微信（身份中枢：注册 / 登录 / 验证）
   ├→ 腾讯企业微信邮箱 support@ ──自动转发──→ QQ邮箱（你每天看）
   ├→ DigitalPlat 域名面板（注册与续期需要扫码/验证）
   └→（开通时）企业微信注册

本机开发机 ──git push──→ GitHub ──自动构建部署──→ Netlify ──读写数据──→ Neon
                            │
                    私有仓库 quotemint-ops（凭证备份，仅你可见）

客户 ──扫码付款──→ 支付宝（你人工核对）──→ 开通命令 scripts/grant ──写──→ Neon（升级 Pro）
```

## 在用平台（逐一说明）

### 1. GitHub — 代码托管 + 部署源头
- 网址 https://github.com ｜ 账号名见 `账号信息.md`
- 两个仓库：**公开** `quotemint`（全部代码和文档）；**私有** `quotemint-ops`（账号凭证备份，仅你可见）
- 你推送代码后 Netlify 自动上线——它是整条部署链的起点
- 免费无限私有/公开仓库；本机已配置 SSH 密钥（免密推送）

### 2. Netlify — 网站托管（生产）
- 网址 https://app.netlify.com ｜ **GitHub 一键登录**
- 职责：托管线上网站 + 运行后端函数 + 自动 HTTPS；全部密钥存在它的"环境变量"里
- 免费版：每月 300 credits（正常用量远远用不完）；备用地址 `quotemint.netlify.app`
- 注意：仓库文件里出现与密钥同名的普通值会触发"密钥扫描"误拦（已设豁免，勿删）

### 3. Neon — 生产数据库
- 网址 https://console.neon.tech ｜ **GitHub 一键登录**
- 职责：存放生产全部数据（用户、报价、签收、打开记录）
- 免费版：额度对早期足够；云托管、免运维，有历史备份；将来直接升付费档（代码零改动）

### 4. DigitalPlat — 免费域名与 DNS
- 网址 https://dashboard.digitalplat.org
- 域名 `quotemint.dpdns.org`：永久免费，**2027-10-13 到期、到期前 120 天可免费续期**
- DNS 托管在这里：A 记录指向 Netlify、www 跳转、邮箱的 MX/SPF 记录也在此维护
- 注意：CNAME 值必须**带结尾点**（否则自动拼错后缀）；面板 API 变更需 CSRF 头（Claude 处理）

### 5. 腾讯企业微信邮箱 — 客服邮箱
- 管理 https://work.weixin.qq.com ｜ 读信/回信 https://exmail.qq.com （微信扫码登录）
- `support@quotemint.dpdns.org` = 主邮箱**别名** + **自动转发**到你的 QQ 邮箱
- 注意：**一个微信只能绑定一个企业邮箱**——这正是当初改用"别名方案"的原因

### 6. 微信 — 身份验证中枢
- 它本身不是网站组件，但注册/登录/验证处处用它扫码（企业微信、exmail、DigitalPlat）
- **保护好你的手机和微信**：它是打开多个平台的总钥匙

### 7. QQ邮箱 — 你的日常收件箱
- 客户来信、付款通知都会**自动转发**到这里；平时看 QQ 邮箱即可
- 以 support@ 名义正式回信时才需要去 exmail.qq.com 扫码

### 8. 支付宝 — 收款
- 收款码在网站账单页展示（图片存放于代码仓库 public/）
- 个人收款码 0 手续费；注意：长期经营收款有合规风险，上量后应换**商家码**或启用 Creem

## 备用 / 休眠平台（代码已就绪，暂未启用）

### 9. Creem — 海外自动收款（首选备用）
- 面向海外客户的 $9/月 订阅制收款；代码适配器已内置
- 启用方式：将来申请商户后配置 3 个环境变量即可（无需改代码）

### 10. Stripe — 海外收款备胎
- 代码同样支持；大陆个人无合规主体，暂只保留兼容性，不安排任何操作

## 已搁置 / 已排除（存档备查，避免走弯路）
