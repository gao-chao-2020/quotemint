# QuoteMint 换电脑迁移清单（换机器 / 脱离 Claude 的恢复步骤）

> [English](MIGRATION.en.md) | 中文

> 目标：换一台电脑（甚至只用手机）后，你仍然能**完整运营** QuoteMint——不需要原来那台电脑、不需要 Claude。日常运营全部走浏览器，零安装。

## 0. 换电脑之前，在原电脑上做两件事

1. 确认 `账号信息.md` 已同步到私有仓库 quotemint-ops（让 Claude 同步一次即可；或在 `ops-repo` 目录自行 `git add -A && git commit && git push`）。
2. 确认你记得 GitHub 账号的登录方式（它是恢复一切的起点，用绑定的邮箱可找回密码）。

## 1. 第一站：GitHub——拿回"钥匙串"

任何一台电脑的浏览器打开 https://github.com → 登录 → 打开**私有仓库 `quotemint-ops`** → 里面是 `账号信息.md`（所有平台的账号与密码）。

- 建议：把 `账号信息.md` 下载到新电脑；并把**管理员密码**（见该文件）记到手机备忘录。
- 该文件是明文密码总表，只放在私有仓库，**不要**转发到任何公开位置。

## 2. 日常运营（浏览器搞定，零安装）

| 要做什么 | 在哪里做 |
|---|---|
| 开通/撤销用户 Pro、看统计数据 | 浏览器打开 **https://quotemint.dpdns.org/admin** → 输入管理员密码（在 `账号信息.md` 里） |
| 收客户邮件 / 付款通知 | QQ邮箱（手机 app 或网页，登录信息在 `账号信息.md`） |
| 以 support@ 名义回信 | exmail.qq.com → 微信扫码登录 |
| 核对收款 | 支付宝 app |

## 3. 各平台登录速查（需要时）

| 平台 | 登录方式 | 用途 |
|---|---|---|
| GitHub | 邮箱找回/密码（账号见凭证文件） | 代码、凭证仓库 |
| Netlify | GitHub 一键登录 | 看网站用量、部署记录 |
| Neon | GitHub 一键登录 | 看数据库用量 |
| DigitalPlat | 账号密码（见凭证文件） | 域名续期（每年一次） |
| 腾讯企业微信邮箱 | 微信扫码 | 邮箱管理 |
| 支付宝 | 手机 | 收款 |

## 4. 需要改代码时（进阶，可选项）

1. 新电脑安装 [Node.js](https://nodejs.org)（≥22）+ Git。
2. `git clone` 公开仓库（地址见 README 顶部）→ `npm test` 应显示 150+ 项全绿 → `npm start` 本地运行。
3. 需要 AI 协助开发时：安装 Claude Code，在新电脑的项目目录里继续（凭证第 1 步已拿回）。
   - 备注：本地演示需要 `npm run seed`（先设 `DEMO_MODE=true`）。

## 5. 只用手机也能运转（极端情况）

/admin 管理菜单、QQ邮箱、支付宝、微信扫码——四件事全在手机上完成，网站管理不依赖任何电脑。

## 6. 如果完全不用 Claude / AI（自助运营边界）

| 事项 | 能否自助 | 工具 |
|---|---|---|
| 开通/撤销 Pro、看统计 | ✅ 可以 | /admin |
| 收发客服邮件 | ✅ 可以 | QQ邮箱 / exmail |
| 收款与对账 | ✅ 可以 | 支付宝 |
| 域名续期 | ✅ 可以 | DigitalPlat 面板 |
| 看网站是否正常 | ✅ 可以 | 打开网站 + Netlify 状态页 |
| 改网站文案/功能、修故障代码 | ❌ 需要开发者 | 找任何开发者，或重新使用 AI 工具（代码和文档都完整存档在 GitHub） |

## 7. 建议的定期自检（每季度 10 分钟）

- 登录 /admin：能登录、统计数字正常。
- 给自己发一封测试邮件到 support@，确认 QQ邮箱能收到。
- 打开网站首页和 /healthz，确认正常。
